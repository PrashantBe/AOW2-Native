Game Information
Title: Art of War 2: Global Confederation
URL: https://github.com/PrashantBe/AOW2-Native

Instructions:
Copy ArtOfWar2__Nokia_5800.jar from your own copy of the Nokia 5800 edition (version 1.4.0) to ports/artofwar2/gamedata/.
The original Java ME game runs natively on a small runtime written for this port. No Java runtime or emulator is used.
The game was made for a touch screen: the left stick moves a pointer that acts as your finger.

| Button | Action |
|--|--|
| Left stick | Move the pointer |
| A | Touch at the pointer (hold to drag) |
| DPAD | Scroll the map and move the cursor |
| Y | Fire or select at the cursor |
| X | Confirm, pause menu |
| Start | Confirm, pause menu |
| B | Back |
| L1 | Set rally point (phone key 1) |
| R1 | Destroy building (phone key 3) |
| Select | Information (phone key 0) |
| R2 + L1 | Phone key 7 in selection panels |
| R2 + R1 | Phone key 9 in selection panels |
| L2 | Slow pointer (hold) |
